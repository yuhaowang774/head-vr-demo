# MediaPipe Face Mesh 实时头部姿态检测项目

## 项目简介

基于 MediaPipe Face Mesh 的实时人脸检测和头部姿态估计项目，能够识别头部的上下、左右、前后运动以及转动角度。

## 技术栈

- **MediaPipe Face Mesh**: 人脸网格检测
- **Canvas API**: 面部特征点绘制
- **WebRTC**: 实时视频输入

## 功能特点

- ✨ 实时人脸检测和面部特征点绘制
- 🎯 头部姿态估计（偏航、俯仰、翻滚角度）
- 🕹️ 头部运动识别（上下、左右、前后平移）
- 🖱️ 可拖动的显示窗口
- 👁️ 支持单人脸检测
- 🎨 简洁的白色背景界面

## 快速开始

### 运行项目

使用本地服务器运行项目：

```bash
npx http-server -p 8080
```

然后在浏览器中访问 `http://localhost:8080`

### 浏览器兼容性

推荐使用 Chrome 浏览器以获得最佳体验。

## 功能说明

### 头部姿态信息

- **偏航角（Yaw）**: 左右转动角度
- **俯仰角（Pitch）**: 上下转动角度
- **翻滚角（Roll）**: 左右倾斜角度

### 头部运动信息

- **左右运动**: 头部水平方向移动
- **上下运动**: 头部垂直方向移动
- **前后运动**: 头部深度方向移动

## 使用注意事项

1. 需要摄像头权限
2. 首次加载需要下载模型文件
3. 建议在光线充足的环境下使用
4. 保持面部在摄像头视野内
